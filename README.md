# Solid — Fitness & Nutrition Tracking App

A fitness transformation tracker with workout logging, nutrition tracking (including AI food-photo analysis), recovery tracking, and progress charts. Built with React, TypeScript, Vite, and Tailwind CSS. Fully localized in English, Arabic, German, French, and Spanish.

See `AI_FOOD_SCANNER_SETUP.md` for the one-time backend setup needed for the AI food photo feature.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
